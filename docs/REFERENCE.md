# Зафиксированный эталон OpenFrame

20 ноября 2026 года пользователь выбрал свою установленную копию Keyframe Pro 2. Её версия установлена как **1.7.1**. Последующие версии сайта автоматически не меняют цель сравнения.

## Идентификация

Установленный файл: `D:\Work\wws\wws-unity\Assets\Content\Animations\~Misc~\Maya\Script\Keyframe Pro 2\bin\KeyframePro2.exe`.

В EXE отсутствует стандартная Windows version resource. Поэтому номер не выводился из имени каталога или даты файла: у пользовательского `C:\Users\eduar\Downloads\KeyframePro2-1.7.1.msi` прочитано поле MSI `ProductVersion=1.7.1`, затем его CAB извлечён во временный каталог без установки и запуска. SHA-256 извлечённого EXE **совпал** с установленным.

| Объект | SHA-256 |
|---|---|
| Установленный EXE и EXE из MSI | `9726893879bc5e44bc7169205ff909a0c72bd201a2c83eaeffc77f562cd53432` |
| Пользовательский MSI | `839af2cacfc8bd1def08b1d79d9909d4dcf71d51de4fabf9c2af7c2ae4298e55` |

Размер EXE — 2 681 344 байта. Метаданные и хеши 21 EXE/DLL установленного дерева записаны в [REFERENCE.json](REFERENCE.json). Дополнительно сопоставлены все 22 файла MSI, включая Qt plugins и `qt.conf`: все совпали с установленными по SHA-256. Пользовательские настройки и лицензированное состояние этим не проверяются.

Для этой идентификации использовались свойства установщика, имена, размеры и хеши. Исходники, внутреннее устройство и ресурсы оригинала для реализации не исследовались и исполнителям не передавались. Бинарники оригинала не включаются в OpenFrame.

Неизменённая копия из MSI отдельно запущена в Windows AppContainer без capabilities и без loopback exemption. Перед продолжением приостановленного процесса проверены `TokenIsAppContainer=1` и нулевой `TokenCapabilities`. Windows сообщила заголовок окна `Untitled (Demo)`. Оба инструмента управления окнами завершались с ошибкой запуска `MXC HRESULT 0x8007000F`; визуальный осмотр и сравнительные действия не состоялись. Собственный процесс завершён, временный AppContainer profile удалён. Журнал: `test-results/reference-sandbox/observation.json`; это не сравнительный PASS.

## Следствия для объёма

Официальная [история версий](https://zurbrigg.com/keyframe-pro-2-documentation/kpro2-release-notes) датирует 1.7.1 девятым ноября 2026 года. В целевой объём входят пользовательские и графические оверлеи, добавленные к этой версии, а также ранее появившиеся phi/dynamic-symmetry overlays, выбор аудиодорожки и loop delay с пустым кадром. Их наличие в журнале релизов подтверждает требование, но не все значения по умолчанию и детали интерфейса.

Подробные контракты уточняются по отдельным публичным страницам и обычным наблюдениям интерфейса/API. Полный режим установленной копии, совместимость старых проектов и точное сравнительное поведение пока не подтверждены. Сам номер версии не закрывает эти пункты.

Проверенная сборка OpenFrame 0.1.0 и её ограничения остаются описаны в [ACCEPTANCE.md](ACCEPTANCE.md). Новые изменения под зафиксированный эталон требуют собственных проверок и не наследуют автоматически результаты прежней сборки.
