# OpenFrame 0.2.0 — проверенный этап

20 ноября 2026 года. Эталон: установленный Keyframe Pro 2 **1.7.1**. Полное соответствие пока не подтверждено. Этот отчёт фиксирует конкретный переносимый пакет; последующие изменения исходников требуют новых проверок.

EXE SHA-256: `28ff7123f40832eefd0bbcb18826e39b03ca59cc0d8c9c8727f28e47607a2022`. Все **38 EXE/DLL** совпали с `build-info.json`. Программа находится в `dist/OpenFrame/OpenFrame.exe`; предыдущий проверенный пакет сохранён отдельно. Машинный журнал: [VALIDATION_0_2_0.json](VALIDATION_0_2_0.json).

## Что добавлено

- Общий pan/zoom композиции, сохранение для основного источника/таймлайна, миграция прежних настроек; поворот и отражение остаются у отдельных панелей.
- Редактируемые safe/grid/center/dynamic-symmetry/phi overlays, собственные линии/прямоугольники/эллипсы/полигоны/текст и локальные растровые изображения. Просмотр, capture и экспорт используют общий compositor. SVG, URL, UNC и reparse paths отклоняются.
- Задержка повторения с удержанием последнего или пустого кадра; отмена ожидания через pause/seek и изменение настроек, reverse/ping-pong.
- Метаданные и выбор аудиодорожки, корректное переключение PCM, сохранение, undo, relink и экспорт.
- После успешного Maya playblast — первый захваченный кадр и активация проигрывателя. Highlighted range поддержан без дополнительного последнего кадра; Send/Receive Range продолжает использовать playback range.

Все собственные тестовые процессы OpenFrame/Maya завершены, endpoint тестового экземпляра удалён. Отчёты и хеши перечислены в [VALIDATION_0_2_0.json](VALIDATION_0_2_0.json). Две первоначальные ошибки нового сценария измерения сохранены в журнале: точка попадала в letterbox, а простой zero-crossing считал малые повторные переходы после ресэмплинга. Исправленный сценарий измеряет пиксель внутри исходного изображения и полные звуковые периоды с гистерезисом.

## Оставшиеся границы

Все 22 файла установленного эталона совпали с MSI 1.7.1 по SHA-256. Неизменённая копия запущена в AppContainer с нулём capabilities; Windows сообщила `Untitled (Demo)`. Визуальный доступ через node/CUA не заработал из-за `MXC HRESULT 0x8007000F`, поэтому сравнительные сценарии и pixel parity остаются **UNVERIFIED**. Подробности: [REFERENCE.md](REFERENCE.md).

HDR/высокая битность, сохранение pitch при изменении скорости, отдельный source audio offset, image-sequence Maya capture, tablet/Wintab, расширенный wipe и другие конкретные пробелы перечислены отдельно в [реестре 1.7.1](REFERENCE_1_7_1_MATRIX.md). Их нельзя считать реализованными только по этой приёмке. Исходный закрытый project/wire format также не поддержан.

Реальное выделение диапазона мышью в Maya ещё не проверено; есть synthetic проверки публичного timeControl-контракта. Не измерены акустическая задержка, многочасовой drift и полный ETW/WFP trace дерева процессов. [Сетевая политика](NETWORK_POLICY.md) описывает реализованные ограничения и границы доказательства.
