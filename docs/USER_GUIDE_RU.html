Версия 0.4.4 для Windows. В OpenFrame можно посмотреть анимацию по кадрам, сравнить две версии шота, нарисовать правки и отправить результат коллеге. Если вы работаете в Maya, playblast можно записать сразу в плеер.

Установить OpenFrame и открыть первый ролик

  1. Распакуйте OpenFrame-windows-x64.zip целиком в постоянную папку на компьютере, например D:\Tools\OpenFrame. Откройте эту папку и запустите OpenFrame.exe. Для последующих запусков можно создать ярлык.
  2. Перетащите видео из Проводника в плеер или нажмите Ctrl+I (File → Import File(s)…). Если в проекте несколько роликов, дважды щёлкните по нужному в панели Project.
  3. Нажмите Пробел для старта и паузы. Клавишами ← и → пролистайте кадры. Чтобы запомнить удачную позу, нажмите B. Чтобы написать замечание, нажмите Ctrl+W.
  4. Нажмите Ctrl+S, если хотите вернуться к этой работе позже. Проект сохраняется в файл .oframe. Оригинальные ролики и кадры храните вместе с ним.

Для работы с Maya перетащите файл maya\Install.mel из распакованной папки прямо в окно с 3D-сценой Maya. Появится полка OpenFrame с двумя кнопками. Бирюзовый треугольник OpenFrame запускает плеер. Янтарный ромб OF Maya открывает окно записи и синхронизации.

Обновление. Сохраните открытый проект, закройте плеер и распакуйте новый комплект целиком. Если пользуетесь Maya, перетащите новый maya\Install.mel в окно сцены ещё раз. Это обновит и кнопки полки, и путь запуска плеера. Так же поступите, если перенесли папку программы.

Записать playblast из Maya

  1. Нажмите на полке OpenFrame, затем OF Maya. В открывшемся окне оставьте Automatic, нажмите Connect и дождитесь надписи Connected. Если Maya предложит выбрать из нескольких открытых плееров, укажите нужный и нажмите Connect ещё раз.
  2. В Maya подготовьте вид камеры. Для записи фрагмента выделите его на Time Slider. Например, выделение от 5 до 10 даст кадры 5–9. Без выделения будут записаны кадры от начала до конца установленного диапазона воспроизведения, включая последний.
  3. В окне OF Maya, на вкладке Playblast, установите Open in viewer → A и нажмите Create playblast and import. После записи Maya вернётся на первый снятый кадр. Когда появится Playblast imported, результат будет в плеере.
  4. Измените анимацию. Для следующей записи выберите B и нажмите ту же кнопку. Теперь обе версии готовы к сравнению. Вариант None добавляет запись в список проекта для последующего просмотра.

Что можно настроить при записи

В окне OF Maya Для чего это нужно
Output format AVI — видеоролик. WebM доступен в тех версиях Maya, которые умеют его записывать. PNG, JPG, BMP и TIF сохраняют отдельные изображения и открываются в OpenFrame как один клип.
Resolution Ширина и высота записи. Начальное значение — 1920×1080. Для собственного размера введите значения, кратные четырём.
Advanced → Quality / scale % Качество записи и масштаб изображения. По умолчанию оба значения равны 100. Для полного разрешения оставьте масштаб 100%.
Include audio / Audio source Для ролика включите звук и выберите Time Slider или конкретный звуковой узел сцены. Refresh обновляет список. Под ним видно, какой звук выбран, приглушён ли он и какое у него смещение. Серии изображений записываются без звука.
Timecode from Maya start Подписывает первый кадр номером из Maya. Например, если запись началась с 1001-го кадра, в плеере первый кадр тоже будет подписан 1001.
Advanced Image frame padding задаёт число цифр в именах кадров. Show ornaments включает служебные элементы вида Maya. Render offscreen включает отрисовку вне видимого окна. Reset adapter settings возвращает исходные настройки окна OpenFrame в Maya.

Где найти запись. Нажмите Open Temp Folder в окне OF Maya. Maya покажет папку захватов этого сеанса и её содержимое. Для хранения шота скопируйте нужный ролик или всю последовательность в папку проекта и укажите новое расположение через Relink Source…. Clear Temp Folder предлагает список неиспользуемых записей этого сеанса и удаляет их после вашего подтверждения.

Связать курсоры времени Maya и OpenFrame

Откройте OF Maya → Sync → Sync direction. Для обычной записи playblast можно оставить Off. Если вы правите анимацию и хотите рядом видеть референс на том же кадре, выберите Maya → OpenFrame. Для разбора замечаний удобно направление OpenFrame → Maya. Тогда переход к кадру в плеере передвинет курсор в сцене. Bidirectional позволяет перемещаться с любой стороны.

  • Начать с выделенного диапазона. Задайте In/Out в плеере, включите From range start, оставьте Multiplier равным 1 и Offset равным 0. Теперь кадр 1 в Maya покажет первый кадр диапазона OpenFrame.
  • Совместить начало шота. Например, если кадру 1001 в Maya должен соответствовать самый первый кадр ролика, выключите From range start, поставьте Multiplier 1 и Offset −1001. Проверьте совпадение на первой позе.
  • Изменить скорость соответствия. При Multiplier 2 один кадр вперёд в Maya сдвигает плеер на два. Если движение уже совпадает, а изменить нужно только подпись первого кадра, введите Display offset и нажмите Apply display offset. Disable override возвращает обычную нумерацию.
  • Перенести границы. Send Maya range отправляет диапазон воспроизведения Maya в плеер. Receive OpenFrame range переносит установленный In/Out в Maya. Диапазон переносится по нажатию кнопки.
  • На вкладке Sync можно выбрать Single A, Single B, Active, Horizontal, Vertical и поменять A и B местами. В плеере Tools → Maya Tools… показывает подключённые сеансы Maya. Если открыты две сцены в разных экземплярах Maya, выберите нужный сеанс перед изменением его настроек. Disconnect в OF Maya завершает подключение.

Сравнить две версии

На верхней панели плеера есть списки A, B, C и D. В A выберите исходную версию, в B — исправленную. В каждый список можно назначить отдельный ролик или целый таймлайн. Пункт Active timeline подставляет текущий таймлайн. Режим сравнения выбирается в Video → Layout или кнопками рядом со списками.

Что хочется увидеть Какой режим выбрать
Только первую или только вторую версию Single A всегда показывает A, Single B всегда показывает B.
Одну версию на всю область просмотра с возможностью менять выбор Active следует за выбранным слотом A или B. Выберите источник в верхнем списке нужного слота или щёлкните по его области в разделённом виде перед переходом в Active.
Оба кадра целиком Horizontal ставит A слева и B справа. Vertical ставит A сверху и B снизу.
Проверить, где изменились контур или освещение Wipe накладывает кадры друг на друга и показывает по разные стороны границы. Потяните линию через интересующий участок.
Сравнить силуэты и положение персонажа Transparency смешивает изображения. При 0% виден A, при 100% — B. Поставьте ползунок примерно посередине и потяните его. Изображение меняется во время перетаскивания, а Ctrl+Z при закрытых инструментах рисования отменяет весь жест.
Сравнить до четырёх вариантов Grid открывает также списки C и D. В верхнем ряду находятся A и B, в нижнем — C и D.

Поменять версии местами можно через Swap Timelines A/B (Ctrl+Tab). Раскладка при этом сохранится. Если для проверки нужен собственный звук или полный хронометраж второй версии, включите Single B. В остальных режимах основной звук и шкалу времени задаёт A.

Точная настройка Wipe. Потяните центральную точку линии, чтобы переместить опору, или круглую рукоятку, чтобы повернуть линию. Ctrl временно отключает привязку к центру и прямым углам. При включённом рисовании удерживайте Alt для перемещения границы. В Video → Wipe можно включить направляющие, задать угол, отцентрировать границу по одной оси или вернуть её в центр через Reset Wipe. Wipe Options… позволяет ввести положение и угол точно. Esc отменяет незавершённое перетаскивание.

Проверить резкость, цвет и композицию

Если playblast выглядит мягче в плеере, у трёх настроек разные задачи.

Настройка Что она меняет
Maya → Playblast → Resolution и scale % Сколько пикселей Maya запишет в сам файл.
Edit → Project Settings… → Viewer output В каком размере OpenFrame собирает изображение для просмотра. У нового проекта это 1920×1080. При показе двух или четырёх версий каждая занимает часть этого кадра.
File → Export to File… → Resolution Сколько пикселей получит готовый экспорт. Этот размер можно задать отдельно.

Для проверки мелких деталей выберите Single A или Single B, посмотрите размер исходника в Details → Properties, поставьте такой же Viewer output и нажмите Ctrl+/ для сброса масштаба. Video → Size → Original Size подгонит окно под исходный размер в пределах экрана. Если свободного места меньше, разверните плеер по F11 или увеличьте нужный участок.

  • Приблизить и сдвинуть. Ctrl+колесо мыши меняет масштаб. Ctrl и перетаскивание средней кнопкой двигают изображение. С добавленным Shift то же перетаскивание меняет масштаб. Команды Video → Pan / Zoom позволяют сдвинуть кадр в любую сторону или сбросить вид. Двойной щелчок при выключенном рисовании также возвращает исходный вид. В Video → Size есть четвертной, половинный, исходный и двойной размеры окна.
  • Проверить позу в зеркале. Выберите нужную область, затем Video → Flip Horizontal или Flip Vertical. Rotate CW / CCW поворачивает её, Reset Flip / Rotate возвращает исходную ориентацию.
  • Наложить направляющие. В Video → Overlays доступны безопасные поля Safe Area, сетка Grid, центр Center, линии Dynamic Symmetry и Phi Grid. Overlay Options… меняет цвет, толщину и прозрачность линий, число делений сетки, размер центра и поля. Toggle Last Overlay прячет и возвращает выбранную направляющую.
  • Использовать свою рамку. Включите Video → Overlays → Custom, затем в том же меню откройте Overlay Options… и добавьте линию, прямоугольник, эллипс, многоугольник или текст. Точки задаются долями ширины и высоты от 0 до 1. Фигуры можно копировать, прятать, удалять и менять их порядок. Image накладывает локальную картинку с регулируемыми положением, размером, пропорциями и прозрачностью.
  • Показать информацию о кадре. Tools → Media Info выводит номер кадра, время и FPS. Video → Picture Type (I / P / B) добавляет тип видеокадра, когда он известен. Эти надписи входят в экспорт вида. Для чистого изображения отключите их перед выдачей.
  • Посмотреть HDR-материал. Плеер показывает изображение в 8-битном sRGB. В Video → HDR / Display Color… можно включить преобразование яркости HDR для экрана. Для точной подстройки доступны яркость источника (Source peak), опорный белый (Reference white), яркость дисплея (Display peak) и переход между яркостями (Mobius transition). Для сохранения исходного цвета в файле используйте настройки экспорта.

Управлять воспроизведением и звуком

Задача Действие
Прокрутить вперёд или назад Пробел запускает и останавливает просмотр. J — назад, K — пауза, L — вперёд. На панели скорости выберите, например, 0.5×, чтобы замедлить движение. Там же можно ввести своё значение от 1/16× до 16×, в том числе со знаком минус для обратного хода.
Найти конкретную позу Потяните по изображению влево или вправо при закрытых инструментах рисования, щёлкните по шкале времени или введите номер в поле текущего кадра. Колесо мыши и ← / → листают по кадру. Shift+← / Shift+→ — по десять кадров.
Повторять только часть движения На первом кадре нажмите I, на последнем — O. Границы также задаются полями In / Out и золотыми маркерами шкалы. В Playback → Looping включите Loop. Ctrl+R возвращает весь диапазон.
Перейти к началу движения или к склейке Home / End — начало и конец материала. Ctrl+Home / Ctrl+End — начало и конец диапазона. Ctrl+← / Ctrl+→ — соседние склейки активного таймлайна.
Увидеть ключевые положения Playback → Set Playback Frame Step… задаёт шаг проигрывания. Поставьте 2 для показа через кадр, верните 1 для показа всех кадров. Чтобы смотреть только отмеченные позы, поставьте закладки и запустите просмотр по ним (Ctrl+Пробел).

Две шкалы времени. Global Time Control показывает весь материал, Range Time Control разворачивает выбранный In/Out на ширину шкалы. Клавиша T меняет их местами. Двойным щелчком по шкале можно добавить заметку.

Поведение на границах. Play Once проигрывает один раз, Loop повторяет, Ping-Pong чередует движение вперёд и назад. Ctrl+L переключает эти режимы. Loop Delay… задаёт паузу между проходами, Hold Empty Frame During Delay показывает в паузу пустой кадр. При ручном поиске Loop on Step / Scrub разрешает перейти через край, Loop Step / Scrub to Range использует края диапазона, Lock Step / Scrub to Range останавливает на границе. Autoplay автоматически начинает воспроизведение после импорта или смены основного материала.

Звук. ↑ / ↓ меняют громкость, M выключает или возвращает звук. В Audio → Source Audio Track можно выбрать другую дорожку ролика. Audio Scrub (Shift+S) даёт коротко услышать звук при перемотке — удобно для поиска начала реплики. Preserve Pitch When Changing Speed сохраняет высоту голоса при замедлении. Если звук опаздывает, выберите источник и откройте Edit → Source / Timeline Properties… → Source audio offset. Положительное число миллисекунд сдвигает звук раньше, отрицательное — позже. Изменение действует во всех клипах, где используется этот источник.

Работать с проектом и таймлайном

Источник — файл или серия изображений. Клип использует выбранный фрагмент источника. Таймлайн собирает клипы в нужном порядке. Например, один длинный playblast можно дважды положить на таймлайн и оставить в каждом клипе разную часть движения.

  1. Добавьте материал. Ctrl+I позволяет выбрать несколько видео, звуковых файлов или изображений. File → Import Folder… добавляет подходящие файлы папки как отдельные источники. Чтобы серия картинок стала одним клипом, используйте File → Import Image Sequence…. Выделите кадры и задайте частоту, например 24/1 или 24000/1001. Файлы сортируются по именам, поэтому последовательность вида shot.0001.png, shot.0002.png удобнее для импорта.
  2. Соберите порядок. В панели Project нажмите правую кнопку и выберите New Timeline…. Дважды щёлкните по таймлайну, чтобы сделать его активным. Перетащите на него источники или выберите у источника Append to Active Timeline. В Details → Timeline кнопки со стрелками меняют порядок клипов.
  3. Подрежьте фрагмент. Дважды щёлкните по клипу. В Clip Properties… задайте Source in и Source out. В этих полях первый кадр исходника имеет номер 0, а последний выбранный кадр включается в клип. Здесь же можно переименовать клип, изменить усиление и смещение звука в секундах или приглушить его. Для озвучки отдельным файлом импортируйте этот файл и выберите в контекстном меню клипа Replace Audio…. Original source audio возвращает исходный звук.
  4. Организуйте проект. Создавайте папки через New Folder…, перетаскивайте в них объекты и ищите их по имени в фильтре Project. В контекстном меню доступны переименование, удаление, назначение в A–D и выбор Default timeline for imports. Если переместили исходник, выберите Relink Source…. Для перенесённой серии укажите первый кадр в новой папке.
  5. Сохраните версию. Ctrl+S сохраняет текущий проект, Ctrl+Shift+S сохраняет под новым именем. Для открытия используйте Ctrl+O. File → Import Project… добавляет другой проект к текущему. Open New Instance открывает второй плеер. В Recent Files и Recent Projects можно вернуться к недавней работе.

В Edit → Project Settings… задаются имя, частота кадров проекта и размер изображения Viewer output. Флажок Apply frame rate to all timelines применяет новую частоту к существующим таймлайнам. Edit → Source / Timeline Properties… меняет параметры выбранного материала, включая отображаемый номер первого кадра, масштаб и сдвиг вида. Для последовательностей, отдельных изображений и таймлайнов можно задать свою частоту кадров.

Нарисовать правку поверх кадра

  1. Остановите воспроизведение на нужной позе и нажмите F8. В режиме сравнения выберите область той версии, к которой относится правка.
  2. Выберите Pencil для свободной линии, Arrow для стрелки, Rectangle или Ellipse для рамки. Нажмите Text и щёлкните там, где нужна надпись. На панели параметров доступны толщина, Opacity и Color. Eraser стирает разметку выбранного слоя.
  3. Для правки одного кадра оставьте FG. Переключитесь на BG, если ориентир должен оставаться на всех кадрах этого источника или таймлайна. Hold удерживает рисунок переднего плана до следующего кадра с рисунком.
  4. Чтобы проверить траекторию, включите Ghost. Рядом с текущей позой появятся рисунки соседних кадров. Правая кнопка по Ghost открывает настройки количества рисунков до и после кадра, их оттенков и подсчёта по кадрам или ключевым рисункам.
  5. Нажмите F8 ещё раз, чтобы выйти из рисования. В Video → Annotations можно показывать рисунки всегда (On), только при остановке (Off During Playback) или временно скрыть (Off).

Исправить или очистить. Esc отменяет незавершённый штрих. Ctrl+Z в режиме рисования отменяет действие на текущем кадре и слое. После выхода из рисования та же клавиша отменяет изменение проекта. Clear Frame очищает рисунки переднего плана текущего кадра. При выбранном BG эта команда очищает общий фон данного материала. Background Fill задаёт цвет и прозрачность подложки.

Показать место во время разбора. Shift+L включает лазерную указку. Проведите линию мышью — след постепенно исчезнет и не попадёт в выдачу. Shift+I включает пипетку. Щёлкните по картинке, чтобы взять цвет для рисования. Esc или правая кнопка завершает работу с указкой или пипеткой.

Планшет и текст. В Edit → Preferences… → Annotation можно настроить нажим карандаша и ластика, сглаживание новых штрихов и параметры лазера. Если перо ведёт себя необычно, проверьте Last pen event и выбор Windows Ink / WinTab. Для ввода текста непосредственно на кадре снимите флажок Use a dialog for text annotations. Ctrl+Enter применяет надпись, Esc отменяет ввод.

Добавить закладку, оставить заметку и передать список правок

  • Пометить позу. Нажмите B для закладки на кадре или Shift+B для закладки на весь текущий In/Out. Повторное нажатие снимает метку. Клавишами , и . переходите между закладками. С Shift переходите между закладками-диапазонами и восстанавливаете их границы.
  • Записать замечание. Нажмите Ctrl+W, введите текст, по желанию добавьте автора и цвет. Список открывается по Ctrl+Shift+B (Notes & Bookmarks). Здесь можно вернуться к замечанию, отредактировать или удалить его.
  • Отобрать нужное. Bookmarks → Filter показывает все метки, пустые, с заметками или с рисунками. Remove Empty Bookmarks удаляет пустые закладки у текущего материала. Ctrl+Пробел или Shift+Пробел запускает просмотр по закладкам внутри диапазона.
  • Перенести рисунок на другой кадр. На исходном кадре выберите Bookmarks → Copy Bookmark или Cut Bookmark, перейдите к целевому кадру и нажмите Paste Bookmark. Вставка заменяет его рисунки FG и при необходимости создаёт закладку.
  • Передать комментарии таблицей. Выберите Bookmarks → Notes → Export CSV…. При обратной загрузке через Import CSV… сопоставьте колонки кадра и текста, при необходимости — автора. Если в таблице номера такие же, как на экране, включите CSV frame numbers use displayed numbering. Проверьте номера и тексты в предварительном просмотре. При обмене внутри того же проекта Preserve matching timeline / source IDs позволяет сохранить привязку к исходным роликам и таймлайнам.

Один кадр для сообщения File → Capture Image → To Clipboard (Ctrl+Shift+C). Затем вставьте картинку в чат. To File… сохраняет кадр как PNG, JPEG или TIFF.
Видео с видимыми версиями, рисунками и направляющими Ctrl+E → Video file → Viewer Capture. Установите нужную раскладку, включите Include annotations, проверьте видимость рисунков.
Видео самих клипов в монтажном порядке Ctrl+E → Video file → Timeline Sources. Так можно получить монтаж без экранного разделения A/B и оверлеев.
Только звук Ctrl+E → Audio file, затем укажите файл WAV или M4A.

Как экспортировать видео

  1. Задайте начало и конец фрагмента через I и O. В File → Export to File… укажите тип результата и путь. Для полной длины включите Ignore range (entire timeline).
  2. Выберите Viewer Capture или Timeline Sources по таблице выше. Введите Resolution и Output FPS. Например, для Full HD с частотой 24 кадра/с поставьте 1920×1080 и 24/1. При обычном экспорте ролика с переменной частотой плеер сохраняет темп движения на заданной постоянной выходной частоте.
  3. Для повседневного просмотра подойдёт MPEG-4 в MP4. Также доступны AVI и H.264 — Windows Media Foundation, если кодировщик есть в системе. Для копии без потерь выберите FFV1 в MKV. Поле Quality (CRF) относится к сжатию при экспорте. Качество playblast в Maya задаётся отдельно.
  4. Проверьте Include audio, Include annotations и количество кадров внизу диалога. Если для рисунков нужен другой фон, при Viewer Capture включите Override annotation background. Нажмите Export. Пока идёт запись, доступна Cancel. По завершении Проводник выделит готовый файл, а для серии — первый сохранённый кадр. При повторной выдаче плеер запросит подтверждение замены, если выключен Force overwrite without confirmation.

Серия изображений. Укажите папку, формат PNG, JPG, BMP или TIFF, общее имя Sequence base name и число цифр Sequence padding. Нумерацию можно начать с 0, 1, собственного числа или выбрать Match timeline frame, чтобы имена совпали с номерами кадров в плеере. Capture every N frames в режиме Viewer Capture позволяет взять, например, каждый второй кадр. В видео с таким шагом выбранные кадры идут подряд с заданным выходным FPS. При сплошной серии изображений Include audio добавляет файл audio.wav. При выборке с шагом или по закладкам сохраняются только изображения.

Если важен цвет исходника. Для обычного просмотра оставьте Display converted (sRGB). Для передачи исходной цветовой кодировки выберите Timeline Sources → Preserve source color encoding. Для видео используйте FFV1 / MKV и выберите Component depth по материалу. Доступны 8, 10, 12 и 16 бит, для HDR с сохранением кодировки нужно минимум 10. Для изображений подходит PNG с явно указанными 16 bit, если профиль источника это допускает. Для материала с ограниченным диапазоном сигнала используйте FFV1. Если сочетание параметров не подходит, пояснение появится в самом окне экспорта.

Tools управляет панелями. Project показывает материалы и таймлайны, Details — свойства и монтаж, Notes & Bookmarks — список правок, Console — сообщения плеера. Edit → Always on Top оставляет окно поверх Maya.

Откройте Edit → Preferences… (Ctrl+,), чтобы изменить привычное поведение плеера.

Частые вопросы

Maya открыла окно OF Maya, но кнопка записи недоступна. Запустите сам плеер бирюзовой кнопкой. В OF Maya нажмите Connect и дождитесь Connected. Если плеер не найден, проверьте Edit → Preferences… → Network → Enable local integration server. При нескольких плеерах выберите нужный в списке OF Maya. Для повторяющейся ошибки ожидания в Advanced → Connection timeout можно увеличить время ответа.

В двух версиях слышна одна и та же дорожка. В режимах сравнения звук идёт из A. Чтобы отдельно услышать B, переключитесь в Single B. Если сам playblast записан без звука, проверьте Include audio и выбранный узел в Maya. Для проверки отдельной звуковой дорожки ролика используйте Audio → Source Audio Track.

После переноса проекта вместо изображения пусто. Файл .oframe ссылается на исходные медиа. Скопируйте ролики или всю папку кадров на локальный диск и воспользуйтесь Relink Source… в панели Project. OpenFrame работает с обычными локальными путями. Для материала на сетевом диске или в папке-ссылке используйте локальную копию.

На экране всё было правильно, а в экспорте видна только одна версия. Перед Ctrl+E верните нужную раскладку. В окне экспорта выберите Viewer Capture. Если нужны и рисунки, проверьте Include annotations и Video → Annotations → On. Для картинки без подписей выключите Tools → Media Info.

Ролик в плеере выглядит менее резким или тяжёлый материал воспроизводится рывками. Для оценки резкости смотрите один слот, проверьте Viewer output и размер исходника. Для разбора движения у тяжёлого HDR-материала можно временно уменьшить Viewer output или использовать облегчённую копию. Перед финальной выдачей снова проверьте размер и цвет. Как проверить изображение

Спрятал меню или панель и не могу вернуть. Ctrl+Shift+M возвращает строку меню. Откройте Tools → Reset Layout или включите отдельно нужную панель. Краткая справка плеера открывается по F1, номер версии — в Help → About OpenFrame….
