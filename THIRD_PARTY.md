# Открытые зависимости

Собственный код OpenFrame распространяется по MIT. Лицензии библиотек сохраняются отдельно; MIT не заменяет их условия.

| Компонент | Версия первой сборки | Использование | Источник |
|---|---|---|---|
| Qt | 6.8.3, MSVC 2022 x64 | Динамические библиотеки Core, Gui, Widgets, Network, Multimedia, Svg; Test для проверок | https://download.qt.io/archive/qt/6.8/6.8.3/ |
| FFmpeg | 7.1.5 | Собственная динамическая сборка avformat, avcodec, avutil, avfilter, swscale, swresample; LGPL 2.1 или новее | https://ffmpeg.org/releases/ffmpeg-7.1.5.tar.xz |
| MSVC runtime | Visual Studio 2022, 14.44.35112 | App-local DLL из официального каталога Redist; условия Microsoft | https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files |

Qt используется по LGPL v3. Модули, требующие исключительно GPL/коммерческую лицензию, не включаются. FFmpeg собирается без `--enable-gpl`, `--enable-nonfree` и без внешних кодеков с этими требованиями. Динамические библиотеки в переносимом дистрибутиве допускают замену совместимыми пользовательскими сборками.

Точные исходники Qt доступны в архиве соответствующей версии. Исходный архив FFmpeg и команда его конфигурации зафиксированы в `tools/dependencies.json` и `tools/build-ffmpeg.sh`. Перед внешним распространением дистрибутива вместе с ним следует предоставить исходники именно поставляемых LGPL-библиотек или соответствующий лицензиям способ их получения; ссылки на сайты сами по себе не заменяют все обязательства распространителя.

aqtinstall и MSYS2 используются только при сборке и не являются частью приложения. Ресурсы и программные файлы Keyframe Pro, animBot и других закрытых продуктов не включены.

Официальные SPDX-описания поставляемых модулей Qt, включая их компоненты и сведения о лицензиях, сохранены в `licenses/qt-sbom`. Тексты LGPL/GPL находятся рядом. Дополнительные плагины Qt для TLS и определения сетевого окружения не включаются в переносимую сборку.
